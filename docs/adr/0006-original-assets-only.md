# Original art and sound, not Yahoo's

Buzz copies Yahoo Messenger's layout, behaviour, and feel, but **every asset is original**: the emoticon faces (`scripts/gen-emoticons.mjs`), the status icons, the Nudge sound (synthesised with Web Audio), and the app icons. We never copy, trace, or sample Yahoo artwork, sounds, or logos, and the UI never uses the Yahoo name, because those are someone else's property. Classic shortcodes such as `:)` are kept, since they are common text conventions.
