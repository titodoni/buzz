👥 Instructions for Hackathon Judges

⚡ Important: Buzz requires two accounts to experience! Buzz is built around presence and real-time interaction between friends. You cannot test the signature Nudge ("Buzz!"), typing indicators, or live presence with only one account. We recommend using two computers (or two accounts on separate windows).

Test credentials are provided in the private testing notes on Devpost, or you can register two new accounts with any email address.

1
Install and Sign In on Two Clients

Download the installer below for your operating system. Launch Buzz on both computers and sign in as Friend A and Friend B.

2
Check the Buddy List & Live Presence

Switch your presence status between Available, Busy, Away, or set a custom status message. Watch the status dot and line update live on your friend's Buddy List!

3
Open a Chat & Send Emoticons

Double-click a buddy in the Buddy List to open a dedicated 1:1 chat window. Type messages, observe real-time typing indicators, and try the 24 classic Yahoo Messenger emoticons (e.g. :), :D, ;), :P).

4
Send a Nudge ("BUZZ!")

In the chat window, click the red BUZZ! button (or press Ctrl+G). Notice how it shakes your friend's chat window with the authentic alert sound! (Has a 10-second cooldown limiter to prevent spam).

5
Try Hangouts & Share What I'm Playing

Send a quick 15-minute Hangout invite ("Coffee break?", "Got a minute?"). Optionally enable Messenger > Share What I'm Playing to broadcast what song is currently playing in your media player.

🛠️ Installation & First Run Steps

Windows 10 & 11

  1. Download and run Buzz_0.1.0_x64-setup.exe.
  2. When Windows SmartScreen shows "Windows protected your PC", click More info → then click Run anyway.
  3. Follow the installer. Buzz will automatically launch and place a shortcut in your Start menu.

macOS

  1. Download the appropriate .dmg (Apple Silicon or Intel) and drag Buzz into your Applications folder.
  2. Open Buzz. If macOS prevents opening:
    • Open System Settings > Privacy & Security, scroll down to the security prompt about Buzz, and click Open Anyway.
    • Alternatively, if macOS reports "Buzz is damaged and can't be opened", run this one command in Terminal to clear the quarantine flag: 
      xattr -dr com.apple.quarantine /Applications/Buzz.app

Linux

  • Ubuntu / Debian: 
    sudo apt install ./Buzz_0.1.0_amd64.deb
  • AppImage: 
    chmod +x Buzz_0.1.0_amd64.AppImage && ./Buzz_0.1.0_amd64.AppImage
    (If FUSE is missing on modern Ubuntu 24.04+: sudo apt install libfuse2t64)

✨ Why Buzz? (Yahoo Messenger Resurrection)

Yahoo Messenger died not because it was bad, but because the feed won: modern chat apps turned into infinite feeds and engagement traps. Presence — the warm feeling of knowing someone is here right now — vanished.

👀 Presence First
The Buddy List is the home screen. See who is Available, Busy, Away, or Offline with zero feed clutter.
💥 The Iconic Nudge ("Buzz!")
Window-shaking, sound-playing wake up call with a 10-second spam limiter and row animation.
😄 24 Classic Emoticons
Pixel-perfect nostalgic Yahoo Messenger emoticons rendered smoothly in every chat window.
🎵 "Now Playing" Broadcast
Broadcast the song currently playing in your media player (Spotify, Apple Music, etc.) to your friends.
☕ Hangouts
Low-pressure 15-minute expiring invitations ("Coffee?", "Quick call?") with one-click responses.
🔒 True Privacy by Design
Only mutual confirmed friends can see each other. No stranger directory, no tracking, no algorithmic feed.

🤖 Built with Kiro (Spec-Driven Development)

Buzz was built from scratch following Kiro's Spec-Driven Development methodology:

  • Requirements in WHEN/THEN Form: Auth, presence transitions, chat delivery, and nudge cooldowns were formally specified before code generation.
  • Strict Technical Steering: Rust toolchain for Tauri v2, Next.js static client export, strict TypeScript (zero untyped any), and full Supabase Row-Level Security (RLS) policies.
  • Automated Agent Hooks: Custom Kiro hooks enforcing pre-commit security verification and testing reminders.
